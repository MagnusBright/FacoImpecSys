# FACOIMPEC E.I.R.L. — Sistema de Gestión Operativa

Prototipo de interfaz web y base de datos en hoja de cálculo para el control de inventario y gestión operativa de FACOIMPEC.

## Archivos del Proyecto
* **PROTOTIPO_FACOIMPEC.html**: Interfaz principal del sistema de gestión.
* **Control stock 2026.xlsx**: Documento base para el seguimiento y control de stock del año 2026.

## Uso
Para visualizar la interfaz, abre el archivo `PROTOTIPO_FACOIMPEC.html` en cualquier navegador web moderno.
